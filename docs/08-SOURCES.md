# External reference register

Reference register dated 3 October 2026. S01–S14 are the technical references retained from revision 2. The new entries support philosophical orientation, continuation instructions, and name provenance at the inspection levels stated below. These sources do not establish the invented story, project estimates, or the merit of proposed creative choices. The implementation team must recheck toolchain details during setup. No external text is embedded in the game's narrative.

## S01: Model availability and intelligence controls

`https://learn.chatgpt.com/docs/models`
