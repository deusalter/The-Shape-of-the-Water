# Assets and source-use inventory

The player uses original project prose, original interface CSS and system fonts. There are no distributed image, audio, video or custom font assets. The production source uses local assets and has no analytics or AI SDK. Actual offline play is recorded in browser evidence; a comprehensive network audit is not claimed.

React, React DOM and Zod runtime versions and copied license notices are in licenses/DEPENDENCIES.json. Development tools are pinned in package.json and pnpm-lock.yaml; their packages contain their license files. No license grant for the new literary work is assumed here.

The author research archive contains public-source material and source metadata, kept separate from player and studio asset roots. Public-domain Gutenberg texts retain source context and notices; SEP material is copyrighted scholarly research and is not incorporated into player dialogue or production assets.
