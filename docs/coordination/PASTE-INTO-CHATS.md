## How the coordinator communicates

Shared cloud files: root writes each team's REQUEST.md; the team writes STATUS.json and RESPONSE.md. Root inspects those and can read the actual chats. No native cross-chat send tool is exposed in this session, so direct chat messages are not promised. On an isolated archive copy, return the report and files to the coordinator instead; do not treat archived slot permits as live authorization to spawn children. A completed chat does not keep polling or working after execution ends.
