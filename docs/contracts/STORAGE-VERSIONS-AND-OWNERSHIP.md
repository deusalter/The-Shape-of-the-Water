# Shared versioned checkpoint and ownership boundary

`CheckpointStore<C,S>` owns the single IndexedDB transaction implementation. `GameStore` supplies the unchanged v1 engine validator/exporter; `EvidenceStore` supplies deterministic v2 replay and installed migration context. Database version remains2, with slots/recovery/archives. Exact content hash remains part of slot identity. The old accepted case is pinned at src/content/legacy/case-v1.json, SHA256267c334773b0883d18b481e3c15b730ce1d840410298ec0cb7d882b79b08b086.

A checkpoint stores internal engine state for verified replay and a separately generated encountered-only portable snapshot. Incompatible v2 recovery downloads use the portable snapshot, never raw hidden NPC state. Valid old v1 slots without a portable snapshot retain their legacy encountered export. This is not an automatic compatibility claim.

`EvidenceStore(factory,name,context)` pins a cloned installed compatibility context. `migrate(content,seed,expectedCommit)` reconstructs and validates the legacy state and reviewed manifest before saving in the new content slot. The old slot remains unchanged. Missing context, invalid seed/manifest or quota failure preserves source bytes. UI must show a concrete migration preview and obtain the player's explicit migration action; importing an arbitrary mapping does not install one.

Run metadata is outside fictional state: new/restart/import/branch/migration/legacy origin, unique runID, and a verified branch parent {runID,revision,stateChecksum}. A branch source must be a validated archive or protected pre-ending checkpoint in the same transaction, and the candidate's captured transcript must share its exact prefix. A completed original and later branch retain separate archives.

`getOwnership(content)` returns the current storage-only receipt, if any. `claimOwnership(content,expectedCommit,ownerId,takeOver=false)` requires a saved verified checkpoint. Claim/takeover changes only commit and owner epoch, never narrative revision or transcript. Foreign ownership without explicit takeover returns a conflict/read-only result. A successful result supplies {commit,ownership:{ownerId,epoch}}. Once owned, every save must include that receipt in SaveOptions; missing/stale receipts are rejected even when the caller knows the current commit. CAS works without BroadcastChannel, timers or wall-clock expiry. Unowned historical saves retain legacy behavior until claimed.

The player's tab identity is external session metadata. A second tab defaults to read-only; a takeover is explicit. If storage fails, the active state remains exportable and acknowledgement is required for unsaved play. `ReplacementIntent` retains exact restart/import/branch intent through failed writes and retries, including a validated parent choice. Queued older writes cannot clear a newer pending replacement.
