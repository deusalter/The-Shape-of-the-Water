# Mercy world

Original Three.js geometry is generated by `src/world/mercy/geometry.ts`. There are no portrait images, GLBs, network model requests or texture dependencies. The old world assets are not imported. The distant curved city is combined into material batches to reduce draw calls; the male protagonist remains an articulated faceless figure with walking limbs.

`src/world/mercy/staging.json` is a pinned copy of the writer's compiler staging, joined to exact module choice IDs and passage variant IDs. `visual/mercy/sync-staging.mjs` updates that pin after `tools/mercy/staging-v7.json` changes. Variant actor/prop/location overrides apply only to their exact encountered variant. Sources in the notebook never imply a present actor or object.

`MercyWorld` accepts `sceneId`, `variantId`, `encounteredSourceIds`, current `choices`, `disabled` and `onChoose`. `hasStaging` rejects unknown scenes/variants. Walking and camera changes have no engine effects. E and the nearby button both recheck the current offered choice and proximity before dispatch. Floor clicks request a bounded path. Visible story actions remain in the root text interface.

Isolated renderer fixture: `/visual/mercy/fixture.html` on the development Vite server. `window.mercyFixture` changes only renderer props and records callbacks; it does not alter game state. `node visual/mercy/browser-check.mjs` visits every pinned scene/variant, compares actual rendered cast/props, executes keyboard movement and pointer-walk/E, checks disabled/hidden rejection and narrow widths. This is software WebGL browser verification, not a human playtest or hardware performance measurement. Current browser evidence is `BROWSER-CHECK.json`; source-independent full game browser checks belong to root.

`provisional-screenshots/` preserves early geometry inspection from deliberately noncanonical fixture stages. The current browser report does not attest those images. Current `screenshots/` are replaced by actual pinned staging visits.

Final held renderer pin: `BUILD.json`. All 62 compiled scenes and 130 scene/variant profiles were visited in the actual isolated browser fixture; eight world tests and typecheck passed. Composition captures at 650px show the market dry hollow, deep stationary rain, a distant Julian on the theatre ladder, and the room/terrace framing. These are actual rendered pixels. Late city/theatre spaces change their cloth/palette and host a modest anonymous gathering. Reset scenes restore their earlier palette and exact current props; recorded departures remove Julian, horse and painted door rather than inferring them from acquired sources.
