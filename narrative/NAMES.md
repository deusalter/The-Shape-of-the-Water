# Name provenance

All names are new provisional choices by the lead writer, not restorations or owner-approved names. Naming sources supply names only. The characters have no historical person's profession, biography, temperament or literary character's plot by inheritance. Readers need no reference knowledge. A present-day English-speaking coastal bath can plausibly have all three names without a code to solve. The revision-3 specification arrived after the initial auditions; its primary-literary-provenance requirement is now reconciled below.

Public pages were fetched on 2026-10-03 through the inherited HTTPS proxy with normal certificate verification. All seven name-source responses returned HTTP 200. Local HTML and normalized text are preserved in `sources/`. Only the stated name locators were inspected for provenance; this is not a claim to have read every page or novel.

Ada's practical occupation was selected before checking Ada Lovelace's name; it is ordinary bath maintenance, not a computing analogy. March, Vane and Verney are not clues. Stable author IDs: `char_001` Ada March; `char_002` Simon Vane; `char_003` Miriam Verney. Normal address is the given name. No pronunciation guide is needed.
